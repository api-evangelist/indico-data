## API Reference
- [Refresh Token](https://developer.indicodata.ai/reference/refresh_token_restapi_api_v1_auth_refreshtoken_post.md): Obtains a refreshed JWT access token using Basic Authentication. Use as the Bearer token for the other endpoints.
- [Get Dataset](https://developer.indicodata.ai/reference/get_dataset_api_v1_datasets__id__get-1.md): Retrieve a dataset by ID.
- [Get Workflow](https://developer.indicodata.ai/reference/get_workflow_api_v1_workflows__id__get-1.md): Fetches a <a href="https://docs.indicodata.ai/smart/project-intake-gen-2-user-guides/create-administer-a-workflow" target="_blank">workflow</a> with the given ID.
- [Submit To Workflow](https://developer.indicodata.ai/reference/submit_to_workflow_api_v1_workflows__id__submissions__post-1.md): Creates a <a href="https://docs.indicodata.ai/smart/project-intake-gen-2-user-guides/submit-files-to-workflow" target="_blank">submission</a> for a given workflow. Provide a single or multiple files. Use one of the `/submissions` endpoints to query for updates and results.
- [Get Submission](https://developer.indicodata.ai/reference/get_submission_api_v1_submissions__id__get-1.md): Gets a specific Submission given the ID
- [Get Submissions](https://developer.indicodata.ai/reference/get_submissions_api_v1_submissions__get-1.md)
- [Get Submission Result](https://developer.indicodata.ai/reference/get_submission_result_api_v1_submissions__id__result_get-1.md)
- [Submit Review](https://developer.indicodata.ai/reference/submit_review_api_v1_submissions__id__review_post-1.md)
- [Mark Submission Retrieved](https://developer.indicodata.ai/reference/mark_submission_retrieved_api_v1_submissions__id__retrieved_put-1.md)
- [Retry Submission](https://developer.indicodata.ai/reference/retry_submission_api_v1_submissions_retry_post.md): Retries processing for a list of failed submissions.  Query Parameters:     `submission_ids`: List of submission IDs to retry  Returns:     List of retried submissions
- [Storage Proxy](https://developer.indicodata.ai/reference/storage_proxy_api_v1_storage__path__get-1.md): This is a convenience method that sits on top of the existing storage endpoint.
